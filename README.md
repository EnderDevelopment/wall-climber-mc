# WallClimber

WallClimber is a Minecraft plugin that allows entities to climb walls and roofs, adding a new dimension to movement and exploration in the game. This plugin is designed for Minecraft servers running on PaperMC or its forks, providing a seamless integration with the existing game mechanics.

## Install

1. Download the WallClimber plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Ensure the plugin is enabled on your server.
2. Players or entities with the appropriate permissions can now climb walls and roofs by moving towards them.
3. The climbing speed and behavior can be configured in the plugin's configuration file.
